# 产品与盈利

## 产品定义

给老师、家长、孩子用的节拍器：会数拍、打开就能用、锁屏还准。不是 Soundbrenner，不做练习社交，不订订阅。

| 场景 | 走哪一端 |
|---|---|
| 浏览器随手开 | Web |
| 微信里练 | 小程序 |
| 老师让回家装一个 | iOS / Android |
| 锁屏练琴、静音键、震动 | 只有原生 |

## 竞品里我们只学这些

- 学 Kr0oked：Android 前台 Service、少权限、无广告
- 学 AVAudioEngine 范本：iOS 采样预约、`.playback`
- 学 Tempo：买断比订阅少挨骂
- 不学 Soundbrenner 的订阅催订
- 不学国内工具的激励视频

童声数拍 + 中英第一等公民，是现在市场里仍然空的位置。

## 钱从哪来

1. **网页打赏**（已有微信 / 支付宝）。小程序跳落地页 `#donate`。
2. **商店音色包** ¥12 一次买断，见 [iap.md](./iap.md)。
3. 以后才谈：教育合作、课堂场景。不当 v1 收入。

明确不做：广告、订阅、付费下载 App、挡默认童声。

## 文案契约

对外可以说：

- 核心功能永久免费
- 无广告、无需注册
- iOS / Android 可选一次买断的额外音色

不要再说「无内购」——原生上架后这是假话，也会被 App Review 抓。

## 分发

- iOS：App Store，先发
- Android：Play 内测 + 官网 APK；国内商店等软著
- 中国手机最大入口仍是微信小程序，不要把国内成功定义成「上了华为商店」
